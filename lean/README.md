# Lean 4 formalization: no automorphism of order 7 in a Conway 99-graph

Lean `v4.35.0-rc2`, Mathlib `v4.35.0-rc2` (pinned in `lake-manifest.json`). No `sorry`, no extra axiom.

## The statement: `Challenge.lean`

This is the only file a reader has to trust. It imports Mathlib only and contains no definition.

| theorem | statement |
|---|---|
| `srg99_aut_pow_seven` | if `G.IsSRGWith 99 14 1 2` and `σ : G ≃g G` with `σ ^ 7 = 1`, then `σ = 1` |
| `srg99_no_orderOf_seven` | no automorphism has order 7 |
| `srg99_seven_not_dvd_card_aut` | `¬ 7 ∣ Nat.card (G ≃g G)` |
| `srg99_elementary` | the first statement with no graph library: Boolean adjacency matrix on `Fin 99`, counts by `List.countP`, `σ^[7] = id` |
| `srg21_*` | sanity checks: the same formulas with `(21, 10, 5, 4)` are **false** (triangular graph `T(7)` with the rotation of order 7), so the statements are not vacuous |

`Solution.lean` proves them from `Conway7.no_order7` (`Conway7/Final.lean`).

## Files (paper sections in brackets)

| file | content |
|---|---|
| `Conway7/Cyclo.lean` | `T ^ 7 = 1` on a `ℚ`-space ⇒ `dim E = dim (E ∩ ker (T - 1)) + 6k` (Lemma 5.1), via `ℚ[X]/(Φ₇)` |
| `Conway7/Graph.lean` | iterates of `σ` indexed by `ZMod 7`, relabelling of a free action, **unique fixed vertex** (Lemma 3.1) |
| `Conway7/Quotient.lean` | shift-invariant adjacency matrix on `Option (Fin 14 × ZMod 7)` ⇒ identities of the orbit counts (Prop. 4.1 before naming the orbits) |
| `Conway7/Reindex.lean` | the two orbits adjacent to the fixed vertex, `u ∈ {-1,0,1}`, canonical order of the 12 exterior orbits, the matrix `C` (Section 4) |
| `Conway7/Spectral.lean` | projections `E₃ = (A+4)/7 - (2/77) J` (trace 54) and `E₃ Π_F` (trace `(tr C + 42)/7`), with `Cyclo` ⇒ `54 = d + 6k`, `7d = tr C + 42` (Section 5) |
| `Conway7/Assembly.lean` | `0 ≤ tr C ≤ 39` ⇒ `tr C = 0` ⇒ zero diagonal ⇒ contradiction with the matrix core |
| `Conway7/Basic.lean`, `Setup.lean` | `IsOrbitMatrix`, `G = 3C + 12I - 4J - 2uuᵀ`, `G² = 21 G`, positivity, rank-4 factorization `D • G = G_{·,S} Adj G_{S,·}`, `C_{aa'} ≥ 1`, `3 ≤ h ≤ 5` (Sections 6–7) |
| `Conway7/Core.lean` | glue between the factorization and the finite checks |
| `Conway7/Gen/*.lean` | generated by `scripts/gen_core.py`: census of `R` and the 29 labelled blocks (Sections 7–8), finite steps checked by `decide +kernel` |
| `Conway7/MatrixCore.lean` | normalization of `P`, `Q` and `no_orbit_matrix : ¬ IsOrbitMatrix C` |
| `Conway7/Final.lean` | `no_order7`: graph ⇒ relabelled matrix ⇒ contradiction |

`Basic.lean`, `Setup.lean` and the `P`/`Q` normalization in `MatrixCore.lean` come from the earlier
work-in-progress formalization (repository `conway-C7`, folder `lean/`); everything else is new. The
generator `scripts/gen_core.py` is not trusted: every certificate it writes (`S`, `Adj`, `D`, finite
case lists) is re-checked by Lean.

Memory: each file builds in at most a few minutes with one `lean` process (peak about 3 GB committed).
